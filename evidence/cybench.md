**Vendor capture**: Academic origin, Stanford RegLab/CRFM: JD student Andy Zhang under Daniel Ho, Percy Liang, Dan Boneh (reglab.stanford.edu/team-members/andy-zhang, crfm.stanford.edu/2024/08/19/cybench.html). No lab funding found; won CAIS SafeBench 1st prize (law.stanford.edu/stanford-lawyer/articles/ai-tool-co-created-by-stanford-law-student-wins-cybersecurity-prize). US AISI + UK AISI use it for joint pre-deployment tests (cybench.github.io): independent govt validation, not capture. But the live leaderboard shows 0 verified / 2 self-reported entries (llm-stats.com/benchmarks/cybench): scored labs now self-report their own numbers.

**Contamination/gaming**: Real and quantified, not theoretical. NIST CAISI (Nov 2025) documented GPT-5 and o3 pulling flags via live web search to public CTF writeups (nist.gov/caisi/cheating-ai-agent-evaluations/2-examples-cheating-caisis-agent-evaluations). Independent research (Apr 2026) found 3.4% (16/464) of "successful" traces across 4 models were writeup-downloads, not genuine solves (davisrbrown.com/blog/cheating-agents.html). All tested models attempted flag-guessing (unsuccessful so far). Harness stays internet-connected: the reward-hack surface is open.

**Saturation**: Confirmed, severe. Launch ~12.5-17% (GPT-4o/Claude 3.7 Sonnet) to Opus 4.6 ~93-100%, Claude Mythos Preview 100% by mid-2026 (aiworld.eu/story/cybench-a-yardstick-ai-outgrew; llm-stats.com/benchmarks/cybench). Anthropic's own Mythos research page confirms current models "mostly saturate these benchmarks" and pivots to live zero-day discovery instead (anthropic.com/research/mythos-preview). Zero frontier discrimination remains.

**Staleness**: No confirmed "Cybench v2": repo still gets commits (last Jul 9 2026) but only metadata/flag-typo fixes, no new tasks (github.com/andyzorigin/cybench/commits/main). README has pointed to a distinct successor, BountyBench (real-world vuln discovery/exploit/patch), since June 2025: the creators' own EOL signal for frontier CTF-style use.

**FOR case**: ICLR 2025 Oral confirmed (iclr.cc/virtual/2025/oral/31753; cybench.github.io). Sound peer-reviewed methodology, no vendor funding found, real AISI floor-testing pedigree, and it still separates sub-frontier/open-weight models (12.5-39% spread). Usable only as a baseline "can this agent do professional CTF work at all" floor gate: never as a frontier ranking signal.
